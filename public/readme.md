1. JSX is a syntax extension for JavaScript. It allows to write HTML structure and elements directly within JavaScript code.

2. 
   (i)Props are like arguments you pass to a function; they let components talk to their children.

   (ii)State is like local variables inside a function; it manages the component's memory and internal dynamic data.

3. useState is a built-in React Hook that lets add state to functional components. It is the primary tool for making      components dynamic and interactive.

4. The primary way to share state between components that don't have a direct parent-child relationship is through State Lifting.

5. 
    (i) CamelCase: Event names are written in camelCase (e.g., onClick, onChange, not onclick).

   (ii) Function Reference: its pass a JavaScript function as the event handler, not a string of code.
